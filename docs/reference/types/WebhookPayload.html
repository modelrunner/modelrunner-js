The JSON body delivered to a webhook endpoint.

It is the same object GET /{owner}/{alias}/requests/{id} returns, plus event and billingStatus — so there is only one shape to learn.

Note the timestamps are ISO-8601 strings, not Date instances: this is whatever JSON.parse produced from the delivered bytes.
